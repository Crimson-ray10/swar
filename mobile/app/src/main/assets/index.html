What this build does

Android on-device STT → lossless text → ITP/1 draft + CRC32 + Hamming FEC → local TCP → offline Android TTS.

Codec: UTF-8, with DEFLATE when smaller. SentencePiece and neural semantic compression are not integrated. VAD uses the recognizer's speech boundaries; separate VAD controls are not available.

Hinglish uses the Hindi recognizer and requires device testing. Speech model names, microphone sample rate, radio bitrate, and end-to-end acoustic latency are not exposed by this pipeline.
